# VYBE STUDIO — Telegram-заказы

Готовый сайт с корзиной, портфолио, пульсирующими значками платформ и серверной отправкой заказов в личные сообщения Telegram.

## Что уже готово

- Кнопка «Отправить заказ в Telegram» собирает ник, контакт, ссылку на канал, ТЗ и позиции корзины.
- `netlify/functions/order.js` проверяет данные и пересчитывает цену **на сервере**: набор плашек 500 ₽, логотип+баннер+офлайн 500 ₽, 5 смайлов 500 ₽, полный комплект 1500 ₽.
- При подтверждённой доставке ботом клиент видит статус успешной отправки. Если отправить не удалось, корзина не исчезает и текст заявки остаётся для копирования.
- **Токен бота никогда не хранится в HTML или JS сайта.**

## 1. Создайте бота Telegram

1. В Telegram откройте **@BotFather**: https://t.me/BotFather
2. Отправьте `/newbot`, задайте боту имя и username.
3. BotFather выдаст **токен**. Не отправляйте его в чат, не публикуйте и не вставляйте в HTML.
4. Откройте созданного бота и нажмите **Start / Начать**. Бот не может первым написать вам личное сообщение.

## 2. Узнайте ваш chat ID

Можно использовать **@userinfobot** (https://t.me/userinfobot) — он показывает numeric Telegram ID пользователя. Сохраняйте только цифровой ID; он будет `TELEGRAM_CHAT_ID`.

Если этот способ недоступен, после того как вы написали вашему новому боту `/start`, выполните приватно в своём браузере (не делитесь адресом!) `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и возьмите `message.chat.id` в JSON-ответе. Не публикуйте URL с токеном и не отправляйте скриншоты с ним.

## 3. Опубликуйте проект с серверной функцией

Рекомендуется **Netlify через репозиторий Git** (напр. GitHub) или **Netlify CLI**, чтобы деплой включал файл `netlify/functions/order.js`. Простая загрузка одиночного HTML-файла не создаёт серверную функцию, и отправка работать не будет.

- Создайте новый сайт на https://app.netlify.com/ с Git-деплоем.
- Разместите **всё содержимое этого архива**, включая папку `assets`, `netlify/functions` и `netlify.toml`, в корне репозитория.
- В настройках Netlify для сайта откройте **Environment variables**, добавьте:
  - `TELEGRAM_BOT_TOKEN` = токен от BotFather
  - `TELEGRAM_CHAT_ID` = ваш цифровой Telegram chat ID
- Если настраиваете область действия переменных, включите **Functions**. После изменения переменных сделайте **Redeploy**.
- Убедитесь, что сайт открывается по HTTPS и функция доступна по `/.netlify/functions/order` (GET должен вернуть JSON с ошибкой метода 405 — это нормально).
- `ALLOWED_SITE_ORIGIN` (необязательно) = полный адрес сайта, например `https://example.netlify.app`, без завершающего `/`. Если зададите эту переменную, не забудьте изменить её при смене домена.

См. документацию Netlify: https://docs.netlify.com/build/functions/environment-variables/

## 4. Проверка

1. Добавьте услугу за 500 ₽ в корзину.
2. Нажмите «Оформить» и заполните ник и Telegram для ответа.
3. Нажмите «Отправить заказ в Telegram».
4. Проверьте личные сообщения **от созданного бота** — там должны быть ник клиента, услуги, итог и ТЗ.

**Важное ограничение:** если открыть `index.html` локально или отправить только HTML-файл другу, отправка по API не будет работать. До публикации и настройки переменных заказ не может реально прийти в Telegram.

## Защита от спама

У функции есть проверка корзины, простое ограничение частоты запросов и скрытое антиспам-поле. Ограничение частоты внутри серверной функции не гарантируется между экземплярами. Для публичного сайта с большим количеством посетителей рекомендуется добавить Cloudflare Turnstile / CAPTCHA.
